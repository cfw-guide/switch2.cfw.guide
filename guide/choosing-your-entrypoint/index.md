# Choosing Your Entrypoint

There are several entry points available for running homebrew on the Nintendo Switch 2. This guide will cover the two that are most commonly used: **Civilization VII** and **SmileBasic 4**.

## Civilization VII

**Civilization VII** is a Nintendo Switch game that can be used as an entry point for homebrew. This title is preferable as it is in a cartridge format that cannot be patched without updating.

There are three variants of the game available:
- **Nintendo Switch 1 (Cartridge)**
- Nintendo Switch 1 (Code in box)
- Nintendo Switch 2 (Code in box)

You must buy the **cartridge version** of the game to use as an entry point, as the exploit only works on v1.0.0 of the game. At the time of writing, all cartridges ship with this version.

## SmileBasic 4

**SmileBasic 4** is another title that can be used as an entry point for homebrew. This game is an eShop only title, and the correct version (v4.4.9) was only available for a few hours before Nintendo pulled it from the store.
::: tip

Continue to <BranchLink branch="smilebasic" to="/guide/preparing-smilebasic/">Preparing SmileBasic 4</BranchLink>

:::

## Other titles

There are other titles that are compatible with other exploits as well, such as Seedsow Lullaby and Balatro. These games have different requirements and are not currently covered in this guide.
